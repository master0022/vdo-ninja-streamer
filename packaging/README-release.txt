VDO-Ninja Streamer - Windows portable release

1. Extract this folder or the ZIP somewhere you control.
2. Run TRANSMITIR.cmd.
3. Use the browser panel to select a window, game, or monitor.
4. Share the viewer link shown in the panel.
5. Close the supervisor when finished. This stops the stream and OBS.

The package includes OBS Studio and does not need Python or .NET installed.
Keep the viewer link private while a stream is active.
